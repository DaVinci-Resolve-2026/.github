Quick start

Up and running in seconds

Download the archive, extract it with the password github, then open the folder for the tool you need and follow its README.

  • Works with DaVinci Resolve 18 and 19
  • Pure Python — no compiled dependencies
  • Every module ships with usage examples
bash
# or clone the repository
git clone https://github.com/CrestGeninPliers/davinci-resolve-toolkit.git

# move into the project
cd davinci-resolve-toolkit

# explore available tools
ls scripts/ presets/ examples/
